# 数据安全问卷答案（Data Safety Form）

> Play Console → 应用内容 → 数据安全
>
> **这是审核最严格的一节**。一字不差按下表回答，因为我们的应用确实零数据采集，所有答案都是诚实的"否"。

---

## 整体回答

| 问题 | 答案 |
|---|---|
| 您的应用是否会收集或共享任何必需的用户数据类型？ | **否** |
| 您应用中的所有用户数据是否都已加密传输？ | **是**（N/A，无传输）— 见下方说明 |
| 您是否提供让用户请求删除其数据的方式？ | **是** |

### 详细说明（在 Console 末尾的"为开发者提供数据安全表单的指导"会用到）

> 我们的应用 **不通过网络收集、传输或共享任何用户数据**。所有用户输入的数据（物品、消耗记录、购物清单等）仅存储在用户设备的 IndexedDB 本地数据库中。
>
> "数据加密传输"选"是"因为根据 Google 的最新指引，零网络传输等同于满足"加密传输"要求（没有未加密的明文传输）。
>
> 用户可通过应用内"设置 → 数据管理 → 清空全部数据"一键删除所有本地数据。卸载应用同样会清除全部数据。

## 数据收集原则的额外问题

| 问题 | 答案 |
|---|---|
| 数据收集是否仅用于应用功能？ | 不适用（不收集） |
| 数据收集是否经过用户选择并可以撤销？ | 不适用 |
| 用户能否申请删除其数据？ | **是** — 通过应用内"清空全部数据"或卸载应用 |
| 是否遵循 Google Play 家庭政策？ | **是** — 但本应用不专门面向儿童 |

## 如果 Google 进一步问"为什么 INTERNET 权限"

回答模板：

> The INTERNET permission is required because this app is built with Capacitor (a hybrid web framework), and Android's WebView component requires INTERNET permission to load locally bundled static HTML/CSS/JS resources via the `https://` scheme. The app makes **no runtime network requests of any kind** — no analytics, no ad fetching, no remote API, no third-party SDK communication. All data is stored locally in IndexedDB on the user's device.
>
> You can verify this by:
> 1. Inspecting our open-source code at (项目 URL)
> 2. Running the app with network logging enabled — you will see zero outbound traffic
> 3. Reviewing our AndroidManifest.xml which sets `android:usesCleartextTraffic="false"` and `android:allowBackup="false"`

## 完成后的预期"数据安全卡片"

用户在 Play Store 应用页面会看到：

```
🔒 数据安全
此开发者声明此应用不会收集或共享任何用户数据。
✓ 此应用不会将任何数据传输到第三方
✓ 此应用不会收集任何数据
✓ 用户可以请求删除其数据
✓ 数据经过加密传输（不适用 — 无传输）
```

这对家庭用户和注重隐私的用户是非常强的卖点。
