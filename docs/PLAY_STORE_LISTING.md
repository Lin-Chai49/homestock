## 完整描述 (Full description) — ≤ 4000 字符

```
🏡 悦家库存 HomeStock —— 让家更井井有条

一款专为中国家庭设计的物资管理应用，帮您管理食品有效期、追踪日用品库存、规划购物清单、分析家庭支出。所有数据保存在您的手机本地，零网络传输，零隐私顾虑，无广告，永久免费。

【为什么需要悦家库存？】

家里总有这些烦恼？
• 牛奶过期了才发现，又浪费了
• 想做菜才发现盐用完了
• 反复购买同款洗衣液，囤了一堆
• 找不到上周新买的胡椒粉放哪了
• 不知道家里这个月在物资上花了多少钱

悦家库存帮您把家里的食品、药品、日用品、清洁用品系统化管理起来，效期到了主动提醒，缺货前自动加入购物清单，月底自动出支出分析报告。

【核心功能】

✅ 库存总览 — 一眼看完家里 100+ 件物资的总数、临期数、库存不足数、本月节约金额。

✅ 物资清单 — "货架式" 卡片网格视图，按食品/药品/日用品/清洁/调味品/罐头/茶饮/其他 8 大类分类管理，支持搜索与多种排序。

✅ 入库登记 — 4 个智能模板（乳制品/蔬果/烘焙/药品）一键填充常用配置；根据品类历史推荐存放位置。

✅ 临期预警 — 紧急（≤2 天，红）/ 临期（3-7 天，橙）/ 关注（8-30 天，黄）/ 新鲜（>30 天，绿） 4 级智能分类，配创意保存建议。

✅ 已过期管理 — 浪费金额、浪费率统计，三大浪费原因分析（遗忘存放 / 购买过多 / 口味变化）。

✅ 库存追踪 — 彩色环形进度环展示日常消耗品剩余比例；基于过去 30 天消耗记录预测耗尽天数。

✅ 存放位置管理 — 12 个预置家庭存放位置（冰箱·冷藏 / 冷冻 / 厨房调料柜 / 米柜 / 茶柜 / 药箱 / 卫生间储物柜 / 清洁柜 / 卧室衣柜 / 客厅储物柜 / 玄关鞋柜）+ 占用率建议。

✅ 智能购物清单 — 库存不足自动加入清单，按推荐商超（盒马生鲜 / 京东超市 / 京东大药房 / 永辉超市）分组，生成最优采购路线。

✅ 消耗记录 — 记录每日早餐、午餐、晚餐、日常 6 大时段的物品消耗，分析消耗规律。

✅ 数据分析 — 6 个月支出趋势折线图、分类占比环形图、购买频率 Top 10、浪费原因分析、效率评分（A/B/C/D）。

✅ 个性化设置 — 3 套主题（家居暖色 / 深色模式 / 清新自然），7 类通知开关，临期阈值与库存阈值可调。

【隐私承诺】

🔒 完全本地存储 — 所有数据保存在您手机的浏览器原生 IndexedDB 中，永远不会上传到任何服务器。
🔒 零数据采集 — 我们不收集您的姓名、电话、邮箱、位置、设备 ID，不收集任何个人信息。
🔒 零第三方 SDK — 无广告 SDK、无统计 SDK、无社交 SDK，应用安装包仅含必要代码。
🔒 仅 1 项权限 — 仅声明 INTERNET（用于加载本地打包的资源），运行时不发起任何网络请求。
🔒 JSON 备份导出 — 您完全掌控自己的数据，可随时导出 JSON 备份保存到本地。

【适合谁用】

• 注重食品健康与有效期的家庭主妇 / 主夫
• 想优化家庭支出的理财型家庭
• 多代同堂、品类多、效期管理混乱的家庭
• 介意个人数据被云端采集的隐私敏感用户
• 不想被订阅收费与广告打扰的用户
```
